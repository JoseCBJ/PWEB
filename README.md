# Web Development Projects

This repository contains various projects that utilize HTML, CSS, and JavaScript. Each project is designed to showcase different aspects of web development, from basic layouts to interactive features.

## Projects Structure

### Project 1: Personal Portfolio
- **Description:** A personal portfolio showcasing my skills and projects.
- **Technologies Used:** HTML, CSS, JavaScript, Bootstrap.

### Project 2: Todo List
- **Description:** A simple todo list application allowing users to add, edit, and delete tasks.
- **Technologies Used:** HTML, CSS, JavaScript.

### Project 3: Weather App
- **Description:** A weather application that fetches API data to display current weather conditions.
- **Technologies Used:** HTML, CSS, JavaScript, API calls.

### Project 4: E-commerce Site
- **Description:** An online store showcasing products with a shopping cart feature.
- **Technologies Used:** HTML, CSS, JavaScript, AJAX.

## Getting Started

To view or run the projects:
1. Clone this repository
2. Open the HTML files in your preferred web browser.
